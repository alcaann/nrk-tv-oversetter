About on-device translation

This extension uses the Translator API built into Chromium-based browsers. Translation runs entirely on your device, and works offline once the language model has downloaded. The list of target languages above is read from your browser, so it reflects what your browser actually supports - Edge 148 and later offers considerably more than Chrome.
